## InstrumentSansLatinSubset 字型子集規格說明

### 1. 基本資訊與屬性 (Basic Specifications)

| 項目                             | 設定值                          | 說明                                                                        |
| -------------------------------- | ------------------------------- | --------------------------------------------------------------------------- |
| **字型家族名稱 (`font-family`)** | `InstrumentSansLatinSubset`     | CSS 中呼叫此字型時使用的名稱                                                |
| **原始字型來源**                 | Instrument Sans                 | 幾何風格無襯線（Geometric Sans-serif）可變字型                              |
| **檔案格式與路徑**               | `./InstrumentSans-Subset.woff2` | WOFF2 可變字型格式 (`woff2-variations`)                                     |
| **本機優先載入 (`src: local`)**  | `Instrument Sans`               | 若使用者裝置已安裝此字型，優先直接使用本機檔案                              |
| **字型樣式 (`font-style`)**      | `normal`                        | 正體（不包含 Italic 斜體）                                                  |
| **載入策略 (`font-display`)**    | `swap`                          | 優先以系統後備字型渲染文字，待字型檔下載完成後自動替換，避免文字隱形 (FOIT) |

---

### 2. 可變軸範圍 (Variable Font Axes)

此子集完整保留了 Instrument Sans 的兩個主要可變軸，允許透過 CSS 精細調整字重與字寬：

- **字重範圍 (`font-weight`)**：`100` 至 `900`
- 支援從 **Thin (100)**、Light (300)、Regular (400)、Bold (700) 到 **Black / Heavy (900)** 的連續調整。

- **字寬/伸展範圍 (`font-stretch`)**：`75%` 至 `150%`
- 支援從 **Condensed 壓縮體 (75%)**、Normal 標準體 (100%) 到 **Expanded 擴展體 (150%)** 的連續調整。

---

### 3. 字元涵蓋範圍 (Unicode Range Coverage)

此子集專為**西歐拉丁語系**與**基本排版符號**設計，包含以下 Unicode 區段與特定字元：

#### 核心字母與符號區段

- **`U+0000-00FF` (Basic Latin & Latin-1 Supplement)**
- 標準 ASCII 字元（大小寫英文字母 A–Z、a–z、數字 0–9、基本標點符號）。
- 西歐主要語言的重音字母（如：`é`, `à`, `è`, `ù`, `ñ`, `ä`, `ö`, `ü`, `ç` 等）。
- 基本印刷標點（連字號、引號、括號、百分比符號等）。

#### 擴充拉丁字母 (Extended Latin)

- **`U+0131`**：無點 i (`ı`)，常用於土耳其文與特定排版。
- **`U+0152-0153`**：拉丁大寫/小寫連字 OE (`Œ`, `œ`)，用於法文排版。

#### 修飾符號與組合音符 (Modifiers & Accent Marks)

- **`U+02BB-02BC`**：翻轉逗號與聲調撇號 (`ʻ`, `ʼ`)，用於夏威夷文或轉寫符號。
- **`U+02C6`**：揚抑符 (`ˆ`)。
- **`U+02DA`**：上圓圈符號 (`˚`)。
- **`U+02DC`**：小波浪號 (`˜`)。
- **`U+0304`, `U+0308`, `U+0329**`：組合用長音符 (`̄`)、組合用分音符 (`̈`)、下方垂直線 (`̩`)。

#### 貨幣與數學/方向符號 (Currency & Symbols)

- **`U+20AC`**：歐元符號 (`€`)。
- **`U+2122`**：商標符號 (`™`)。
- **`U+2191`, `U+2193**`：向上與向下箭頭 (`↑`, `↓`)。
- **`U+2212`**：正交減號 (`−`)（優於標準 ASCII 減號/連字號 `-` 的排版效果）。
- **`U+2215`**：除號斜線 (`∕`)。

#### 系統與控制字元

- **`U+FEFF`**：零寬不換行空格 / BOM (Byte Order Mark)。
- **`U+FFFD`**：替換字元 (``)（當字型解析失敗時顯示的缺字符號）。

### 4. 前端排版與 CSS 使用範例

可以在專案的 CSS 中直接透過樣式屬性呼叫該字型：

```css
body {
  font-family:
    "InstrumentSansLatinSubset",
    -apple-system,
    BlinkMacSystemFont,
    "Segoe UI",
    sans-serif;
  font-weight: 400; /* Regular */
  font-stretch: 100%; /* Normal width */
}

/* 標題套用較重字重與略微壓縮的字寬 */
h1 {
  font-family: "InstrumentSansLatinSubset", sans-serif;
  font-weight: 800; /* Extra Bold */
  font-stretch: 90%; /* 微調字寬 */
}

/* 內聯強調：拉寬字體與細字重 */
.custom-display {
  font-family: "InstrumentSansLatinSubset", sans-serif;
  font-weight: 200;
  font-stretch: 125%;
}
```

## 略過的範圍

與完整的拉丁字集（如 Google Fonts 的 `latin` 或 `latin-ext`）相比，這個子集採取了**極度精簡**的策略：它僅保留了**西歐主要語言（ASCII + Latin-1）**，並大幅略過了中東歐語言、進階印刷標點以及部分常用符號。

以下是此字型子集具體略過（省略）的核心範圍與字元：

### 中歐與東歐拉丁字母 (Latin Extended-A, `U+0100-017F`)

雖然此 block 補上了 `U+0131` (`ı`) 以及 `U+0152-0153` (`Œ`, `œ`)，但**略過了該區段其餘 125 個字元**。

- **略過字元**：如 `Č/č`, `Š/š`, `Ž/ž`, `Đ/đ`, `Ł/ł`, `Ń/ń`, `Ę/ę`, `Ğ/ğ`, `Ā/ā` 等。
- **受影響語言**：波蘭文、捷克文、斯洛伐克文、匈牙利文、羅馬尼亞文、拉脫維亞文、立陶宛文、土耳其文（雖有 `ı` 但缺 `Ğ/ğ`, `Ş/ş`）。

### 印刷級標準標點符號 (General Punctuation, `U+2000-206F`)

除了歐元符號 `U+20AC` (`€`) 外，**整個一般標點區段完全被略過**：

- **略過彎引號/智慧引號 (Smart Quotes)**：
- 單引號 `‘` (`U+2018`)、`’` (`U+2019`)
- 雙引號 `“` (`U+201C`)、`”` (`U+201D`)
- _註：若文案使用這些符號，會退回備用字型渲染。_

- **略過印刷連接號 (Dashes)**：
- En Dash `–` (`U+2013`)、Em Dash `—` (`U+2014`)

- **略過其他常用標點**：
- 省略號 `…` (`U+2026`)
- 項目符號 `•` (`U+2022`)
- 單角引號 `‹` (`U+2039`)、`›` (`U+203A`)

### 越南文與漢語拼音聲調 (Latin Extended-B & Additional, U+0180-024F, U+1E00-1EFF)

- 略過字元：帶有複合音符的拉丁字母（如 Ấ/ấ, Ờ/ờ, Ử/ử）以及漢語拼音的三聲/四聲符號（如 ǎ, ǐ, ǒ, ǔ）。
- 受影響語言：越南文、帶聲調符號的漢語拼音 (Pinyin)、非洲或美洲原住民語言。

### 方向箭頭與數學/符號區段 (Arrows & Symbols)

- **方向箭頭 (`U+2190-21FF`)**：僅保留了向上 `↑` (`U+2191`) 與向下 `↓` (`U+2193`)，**略過了向左 `←` (`U+2190`) 與向右 `→` (`U+2192`)**。
- **數學運算子 (`U+2200-22FF`)**：僅保留了減號 `−` (`U+2212`) 與斜線 `∕` (`U+2215`)，略過了不等於 `≠` (`U+2260`)、約等於 `≈` (`U+2248`)、小於等於 `≤` (`U+2264`) 等。

## 用途：替換其他中文字型(如noto 黑體)中的拉丁字，以便創造不同的排版觀感。有些字元不想替換，所以會刻意略過。

這種透過 `@font-face` 與 `unicode-range` 為中文字型（如 Noto Sans TC）疊加指定西文字型的做法，是網頁中英文混排（Font Pairing）非常標準且精準的實踐方式。

針對「刻意略過特定字元」的設計，在中文排版情境下是非常明智且專業的考量：

1. **標點符號與基線對齊（Baseline Alignment）**
   西文字型與中文字型的字高（x-height）與基線設定不同。若將雙引號（`“` `”`）、破折號（`—`）或破折號替換為西文字型，常會導致符號在中文句子中「偏低」或與前後中文字距離不均勻。讓這些符號保留由中文字型渲染，能維持中文排版的垂直置中與字距空間。
2. **方向箭頭與全形特性的保持**
   西文的左右箭頭（`←` `→`）通常是半形且偏向搭配英文字母的基線；而中文排版中的箭頭符號往往需要具備全形寬度或配合中文字框置中。略過箭頭可避免英文箭頭在中文介面中看起來過於緊湊或偏移。
3. **載入體積（File Size）極小化與避免排版衝突**
   將範圍鎖定在 ASCII 與基本西歐字母，能把 WOFF2 檔案壓縮至極小，同時完全避免西文覆蓋中文字型全形標點所產生的排版衝突（Typographic Collision）。

這樣的子集範圍既能確保英文字母與數字呈現出 Instrument Sans 現代、俐落的可變字體質感，又不會破壞中文字型原有的標點與排版結構。
