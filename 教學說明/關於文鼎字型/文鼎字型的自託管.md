🟨Q：文鼎科技 曾以 ARPHICPL 授權發布 ukai.ttc 及 uming.ttc，這些字型是可以轉成網路字型自託管的嗎？

---

**答案是：完全可以！**

文鼎科技於 1999 年以 **ARPHICPL（Arphic Public License / 文鼎公眾授權書）** 釋出的字型，授權條款中**明確允許轉碼、切片與網路分發**。

你可以將它們轉成 `.woff2` 網頁字型、進行中文子集化切片（Subsetting），並放入你的 GitHub + jsDelivr CDN 進行自託管。

---

### 一、 授權條款依據（ARPHICPL 規範）

根據 1999 年版《文鼎公眾授權書（ARPHICPL）》第 2 條（Modification）之規定：

> _"You may otherwise modify your copy of this Font in any way, including modifying glyph, reordering glyph, **converting format**, changing font name, or **adding/deleting some characters in/from glyph table**, and copy and distribute such modifications..."_
>
> （譯：您可以任何方式修改本字型，包括修改字型樣式、**轉換格式**、變更字型名稱、**在 glyph 表中增減字元**，並依規定複製與分發修改物。）

這代表：

1. **轉換格式：** TTC ➔ TTF ➔ WOFF2，完全合規。
2. **刪除/增減字元：** 使用 `cn-font-split` 進行中文切片（Subsetting），完全合規。
3. **免費商業使用：** 1999 年舊版 ARPHICPL 授權允許免費商業使用。（_註：2010 年文鼎出的新版授權才限制非營利，而 `ukai.ttc` / `uming.ttc` 採用的是 1999 年舊版授權_）。

---

### 二、 背景補充：`ukai.ttc` 與 `uming.ttc` 是什麼？

這兩個檔案是 Linux 開源社群（如 Debian、Ubuntu、Firefly 飛火專案）極為著名的作品：

- **`ukai.ttc`（AR PL UKai / 文鼎 PL 中楷）：** 社群將文鼎原本釋出的 Big5 繁體楷體與 GB2312 簡體楷體合併，並補充大量字碼後的成果。
- **`uming.ttc`（AR PL UMing / 文鼎 PL 細上海宋）：** 社群將 Big5 繁體明體與 GB2312 簡體宋體合併補字後的成果。

因為社群已經幫忙把繁簡體字集融合好了，拿它們來做 WebFont 的涵蓋率非常高！

---

### 三、 自託管時需要遵守的 3 個合規條件

將字型放上 GitHub / CDN 時，只需在 `README.md` 中做簡單說明即可符合 ARPHICPL 的規定：

1. **保留原作者與社群聲明：** 註明原始版權屬於文鼎科技（`Copyright (C) 1999 Arphic Technology Co., Ltd.`），並感謝 Debian/Ubuntu 社群修復。
2. **聲明修改紀錄：** 說明「本字型已由 TTC 拆解為 TTF，並透過 `cn-font-split` 轉碼為 `.woff2` 中文網頁字型切片」。
3. **授權繼承：** 切片出來的 `.woff2` 檔案同樣以 **ARPHICPL** 授權開放。
