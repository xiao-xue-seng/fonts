### 💡 為什麼 Google Fonts 會下架？（重要商用提醒）

- **下架原因：** cwTeX 早期是由社群開發者製作並開放，但後來部分字形的來源被指出可能含有傳統商業字型（如文鼎、寫研）掃描檔的疑慮，因此 Google Fonts 在接到討論後，已於 2018 年左右將 cwTeX 全系列下架。
- **使用建議：**
  - **個人非商業專案 / 學術研究 / 測試：** 可以放心從上方 GitHub 下載 `cwTeXQFangsong-Medium.ttf`，並配合你目前的 `cn-font-split` + GitHub + jsDelivr 流程來切片使用。
  - **商業營利專案 / 企業官網：** 為避免潛在的法律版權風險，建議商業專案可考慮其他版權無爭議的免費/開源仿宋字型（例如：**彙文仿宋**、**華康/教育部標準仿宋**等）。
