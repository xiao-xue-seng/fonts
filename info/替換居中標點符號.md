### 💡 如何讓「寒蟬正楷體」顯示正宗繁體「居中標點符號」？

#### ❓ 為什麼需要調整？

「寒蟬正楷體」源自中國大陸的字型規範（GB 標準），因此它的逗號、句號等標點符號預設是**靠左下角**顯示的。
如果你在繁體中文網頁中使用，可能會覺得標點符號偏低、不太習慣。只要透過簡單的設定，就能讓標點符號像台灣課本一樣**漂亮地居中**！

---

#### ✨ 神奇的運作原理（瀏覽器排隊機制）

我們額外提供了一個專門裝載繁體「居中標點」的迷你字型包（`TW-Kai-Punct` 及 `TW-Sung-Punct`）。

只要在 CSS 中把標點包**排在第一順位**：

1. 當瀏覽器遇到「，。！？」等等標點符號 ➔ **優先使用第一順位的標點包**（呈現居中標點）。
2. 當瀏覽器遇到一般中文字 ➔ 標點包裡沒有中文字，瀏覽器會**自動交給第二順位的寒蟬正楷體**顯示。

---

### 🚀 輕鬆設定 2 步驟

#### 步驟 1：在 HTML 的 `<head>` 中載入標點包

在原本載入寒蟬正楷體的地方，**額外加入一行**全字庫標點包的連結：

```html
<!-- 1. 載入「全字庫居中標點包」（放在上面） -->
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/xiao-xue-seng/fonts@main/tw-kai-punct/result.css"
/>

<!-- 2. 載入原本的「寒蟬正楷體」 -->
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/xiao-xue-seng/fonts@main/chill-kai/result.css"
/>
```

#### 步驟 2：在 CSS 中將標點包放在「第一個」

在設定字型名稱（`font-family`）時，把 `"TW-Kai-Punct"` 寫在 `"ChillKai"` 的**前面**：

```css
/* 順序極度重要：標點包在最前面，寒蟬在後面 */
.text-box {
  font-family: "TW-Kai-Punct", "ChillKai", serif;
}
```

---

🎉 **完成！** 現在你的網頁文字會保持寒蟬正楷體的優美筆畫，而逗號、句號等標點符號則會自動變回正宗的繁體居中格式囉！
