# 自託管 WebFont 倉庫

本倉庫收錄經過中文子集化（`cn-font-split`）切片之免費可商用 WebFont。

## 📦 字型列表與引入方式

### 1. 寒蝉正楷體 (ChillKai)
- **授權**：SIL Open Font License 1.1
- **CSS 引入網址**：
  ```html
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/yourname/fonts@main/chill-kai/result.css">
  ```
- **CSS 套用**：
  ```css
  font-family: 'ChillKai', serif;
  ```
