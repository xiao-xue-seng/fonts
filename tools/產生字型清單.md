# 產生全部字型清單

執行以下指令，會掃描 `.dist` 中已建置的 npm 字型套件，並產生 `api/fonts.json`：

```bash
python tools/generate_font_list.py
```

工具會讀取各套件 `package.json` 的 `name`、`version` 與 `fontMetadata`，並支援群組套件的 `index.css` 及子資料夾 `result.css`。

可用參數：

```bash
python tools/generate_font_list.py --root .dist --output api/fonts.json
python tools/generate_font_list.py --base-url https://cdn.jsdelivr.net/npm/
```

工具會從每個 CSS 的第一個 `@font-face` 讀取 `font-family` 作為 `name`，以資料夾結構作為 `id`，並使用 `fontMetadata.title` 作為 `displayName`。
