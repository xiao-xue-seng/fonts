# 產生全部字型清單

執行以下指令，會掃描專案根目錄下含有 `result.css` 的字型資料夾，並產生 `api/fonts.json`：

```bash
python tools/generate_font_list.py
```

`tools/font-list.config.json` 可設定：

- `excludeFolders`：要排除的資料夾名稱陣列。
- `displayNames`：要覆寫的顯示名稱。預設是字型原名稱。

也可以在執行時額外排除資料夾：

```bash
python tools/generate_font_list.py --exclude some-folder
```

工具會從每個 `result.css` 的第一個 `@font-face` 讀取 `font-family` 作為 `name`，並以資料夾名稱作為 `id`。
